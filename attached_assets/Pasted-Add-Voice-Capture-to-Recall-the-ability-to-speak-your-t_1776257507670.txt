Add Voice Capture to Recall — the ability to speak your thoughts about any webpage and have them saved to your library with full context.
Backend
1. Voice Notes Table (Supabase SQL — run this first):
sqlCREATE TABLE IF NOT EXISTS voice_notes (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  transcript TEXT NOT NULL,
  summary TEXT,
  tags TEXT[] DEFAULT '{}',
  source_url TEXT,
  source_title TEXT,
  page_context TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE voice_notes ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users manage own voice notes" ON voice_notes
  FOR ALL USING (auth.uid() = user_id);
2. New route: POST /api/voice-notes
Accepts: { transcript, source_url, source_title, page_context }

Parse inline tags from transcript — any phrase 'tag: X' or 'hashtag X' extracts X as a tag
Call Claude Haiku to generate a one-line summary of the transcript
Generate embeddings and store in Supabase
Return the saved voice note

3. New route: GET /api/voice-notes
Returns all voice notes for the authenticated user ordered by created_at descending.
4. New route: DELETE /api/voice-notes/:id
Deletes a voice note belonging to the authenticated user.
5. Update POST /api/saved/ask
When answering a question across the library, also fetch the user's voice notes and include them as context. Prefix voice note context with 'From your voice note on [source_title]:' so Claude can distinguish them.

Inline Tag Parsing Logic
Parse these patterns from transcript text:

'tag: X' or 'tags: X' → extract X as tag
'hashtag X' → extract X as tag
'#X' spoken as 'hash X' → extract X as tag
Strip the tag syntax from the displayed transcript but store tags separately.

Important

Web Speech API is free, works natively in Chrome, no API key needed
All transcription happens in the browser — nothing is sent to any external service for transcription
Only the final transcript text is sent to your backend
Show a clear privacy notice on the Voice Note tab: 'Your voice is transcribed locally in your browser. Only the text is saved to Recall.'
Keyboard shortcut Ctrl+Shift+V must not conflict with browser defaults"
