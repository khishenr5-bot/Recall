Design System to implement exactly:

Typography
Import Google Fonts: Manrope (display/headlines) and Inter (body/labels).

Display: Manrope, 3.5rem, weight 700 — hero moments only
Headlines: Manrope, 1.5-2rem, weight 600
Body: Inter, 0.875-1rem, weight 400
Labels/Metadata: Inter, 0.6875rem, ALL CAPS, letter-spacing 0.08em, weight 500

Critical Design Rules

NO 1px solid borders for sectioning — use background color shifts between surface tokens
Ghost borders only: rgba(64, 72, 93, 0.15) when absolutely needed for accessibility
Cards: background surface-high, 24-32px padding, 0.5rem border-radius, NO dividers
Glassmorphism on all modals and floating panels: backdrop-filter blur(12px), semi-transparent surface-mid background
Primary CTAs: linear-gradient from #a3a6ff to #6366f1
Input focus: primary color border + 8px glow rgba(163, 166, 255, 0.15)
Hover states: surface-bright background (#1f2b49)
Ambient shadows on floating elements: 0 16px 48px rgba(163, 166, 255, 0.06)
NO hard corners — minimum 0.375rem border-radius everywhere
Metadata labels in ALL CAPS with increased letter spacing
