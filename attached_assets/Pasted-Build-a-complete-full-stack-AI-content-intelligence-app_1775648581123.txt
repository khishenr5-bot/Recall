Build a complete full-stack AI content intelligence app called Recall.ai — 'Understand more. Read less.'
Tech Stack

Frontend Web: React + TypeScript + Tailwind CSS + Framer Motion
Mobile: React Native + Expo
Backend: FastAPI (Python)
Database: Supabase (PostgreSQL + Auth)
AI: Anthropic Claude API (claude-haiku for free tier, claude-sonnet for pro)
Email: Resend API
Payments: Razorpay
Scraping: Jina Reader API (https://r.jina.ai/{url}) as primary, BeautifulSoup as fallback
YouTube: YouTube Data API v3
TTS: Google Cloud TTS API

Core Concept
Users paste any URL (article, YouTube video, podcast, PDF, DOCX, TXT) → Recall fetches the content → Claude AI generates a verdict (is it worth your time?) + dynamic bullet points (3-10 based on content depth) → user can ask questions about the content → save to personal library → build a second brain over time.
Authentication

Supabase Auth with email/password
Google OAuth login
Each user has completely private library
JWT tokens for all API calls
Onboarding flow for first-time users (4 steps: welcome, demo, extension, language preference)

Backend API Endpoints
Summarisation

POST /api/summarize — accepts {url} or multipart file upload (PDF/DOCX/TXT), detects YouTube URLs and uses YouTube Data API, uses Jina Reader for all other URLs, calls Claude to generate verdict + bullets, returns {title, verdict, bullets, articleText, language, credibility_score}
POST /api/suggest-questions — accepts {title, verdict, bullets}, returns 3 suggested follow-up questions
POST /api/audio-brief — accepts {title, verdict, bullets}, generates conversational script between Aria and Ravi discussing the content
POST /api/tts — accepts {text, language_code}, uses Google Cloud TTS, auto-detects language with langdetect, returns base64 audio

Library

GET /api/saved — list user's saved articles with pagination
POST /api/saved — save an article with all fields
DELETE /api/saved/:id — delete saved article
PUT /api/saved/:id/collection — assign to collection
POST /api/saved/:id/share — generate public share token
GET /api/share/:token — public endpoint, no auth required

Ask AI

POST /api/saved/ask — accepts {question}, fetches all user's saved articles, answers using Claude with citations
POST /api/rabbit-hole — accepts {title, verdict, bullets}, suggests 5 related articles to read next

Collections

GET /api/collections — list user's collections
POST /api/collections — create collection with name + color
DELETE /api/collections/:id — delete collection

Highlights

GET /api/highlights — list user's highlights
POST /api/highlights — save a bullet as highlight
DELETE /api/highlights/:id

Digest & Reports

GET /api/digest/preview — returns 3 most recent saves formatted for email
POST /api/digest/send — sends daily digest email via Resend
GET /api/report/weekly — generates weekly reading report with themes, top saves, patterns

Insights

GET /api/insights/reading-dna — topic breakdown + reading patterns for last 30 days
GET /api/mentor/recommendations — 3 knowledge gaps + suggested reads based on reading history
GET /api/review/due — articles due for spaced repetition review
POST /api/review/:id/complete — mark article reviewed

Payments

POST /api/payment/create-order — creates Razorpay order for ₹499/mo
POST /api/payment/verify — verifies payment, upgrades user to pro in Supabase

Developer API

POST /api/developer/keys — generate API key
GET /api/v1/saved — public API with API key auth
POST /api/v1/save — public API save endpoint

Sharing

POST /api/saved/:id/share — generate unique public share link
GET /api/share/:token — public shareable summary page
