STEP 2 — Generate all icons programmatically:
Create a script scripts/generate-icons.js that uses the canvas npm package to generate all required icon sizes (72, 96, 128, 144, 152, 192, 384, 512) plus shortcut icons. Each icon should be a dark navy #060e20 square with a simple brain/neural icon in indigo #a3a6ff gradient drawn with canvas paths. Also generate maskable versions with safe zone padding. Save all to public/icons/ folder. Run the script.
STEP 3 — Generate screenshots automatically:
Create a script scripts/capture-screenshots.js using puppeteer to visit the app URL and capture screenshots at 1280x720 (wide) and 390x844 (narrow) for home page and library page. Save to public/screenshots/. Run the script.
STEP 4 — Create widget API endpoints:
Add GET /api/widget/quick-save — returns JSON with user's recent saves count and a save form template.
Add GET /api/widget/digest — returns today's top 3 saved articles as JSON formatted for the widget.
Both endpoints accept the user's API key as a query param for auth since widgets can't use JWT.
STEP 5 — Create file handler page:
Add route /handle-file in the React app. When a PDF, DOCX, TXT, or EPUB file is opened with Recall on Android, this page receives the file, automatically sends it to the summarise endpoint, and redirects to the result. Show a loading spinner while processing: 'Recall is reading your file...'
STEP 6 — Create share target handler:
Add route /share-target in the React app. Reads the shared URL or text from query params, automatically triggers summarisation, shows the result. Back button goes to library.
STEP 7 — Handle shortcut actions on home page:
On the home page, read the ?action query param on load:

action=save → focus the URL input immediately
action=voice → immediately start voice recording
action=research → switch to Deep Research tab and focus input

STEP 8 — Update service worker for full offline support:
Update the service worker to cache: all app shell files, all icon files, last 50 saved articles from the library, the home page. When offline, show cached library content with an offline banner. Queue any save requests made offline and sync when back online using Background Sync API.
